> **Iberio** (formerly Iberacademy) is a modern, cross-platform application designed to accelerate Spanish language acquisition. By leveraging custom AI personas, regional dialect support, and a highly optimized Progressive Web App (PWA) architecture, Iberio delivers a tailored, immersive learning experience right to your browser or mobile device.

---

## ✨ Key Features

*   🤖 **AI Tutor Personas:** Interact with specialized AI personas designed to simulate real-world conversations and provide structured feedback.
*   🌎 **Regional Dialect Support:** Master nuances in pronunciation and vocabulary with built-in Mexican dialect support (and more to come).
*   📱 **Cross-Platform Ready:** Built with Capacitor and fully optimized as a PWA for a native-like mobile experience.
*   ⚡ **High Performance:** Lightning-fast rendering and optimal load times powered by Vite and the Bun runtime.
*   ☁️ **Cloud Infrastructure:** Seamless real-time data syncing and user management powered by Firebase and Firestore.

---
